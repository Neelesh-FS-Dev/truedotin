# True.in: private creator-culture website concept

Independent creative proposal by Codevirel Studio. **Not an officially commissioned True.in website.** Keep it private until True.in and the rights holders of the media have authorised publication.

Design rationale, references and verification status: [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md).
Media rights and per-item decisions: [docs/MEDIA_INVENTORY.md](docs/MEDIA_INVENTORY.md).
QA results, including what was not tested: [docs/QA_REPORT.md](docs/QA_REPORT.md).

## Stack

React 19, Vite 8, TypeScript (strict), React Router 7, GSAP with ScrollTrigger, Lenis, self-hosted Bricolage Grotesque, General Sans and IBM Plex Mono. Vitest for unit tests and playwright-core for browser checks.

## Commands

```bash
npm install
npm run dev          # local development
npm run typecheck    # tsc --noEmit
npm test             # vitest (validation, filters)
npm run media        # rebuild public/media from the original files in the project root (needs macOS: sips, avconvert, and Google Chrome)
npm run build        # typecheck, production build, sitemap (only if SITE_URL is set)
npm run preview      # serve dist/ on port 4173
```

Original photos and videos stay in the project root as `truedotin_*.jpg` and `truedotin_*.mp4`. They are git-ignored. `public/media` is generated from them. It is about 134 MB, so commit it only to a private repository, and only with rights cleared.

## Content

- `src/content/campaigns.ts`: archive entries (title, category, date, description, media IDs). Titles describe visible content. No client, outcome or result is claimed.
- `src/content/media.generated.ts`: generated by `npm run media`. Do not edit by hand.
- `src/content/site.ts`: navigation, contact routes and the concept disclosure. Unverified details are `null` (business email and phone).
- `src/content/capabilities.ts`: the five service areas. Each is described as a proposal.

## Private deployment

The site is `noindex` on every page, `robots.txt` disallows crawling, and no sitemap is produced unless `SITE_URL` is set to a confirmed origin. **These do not restrict access.** For real access control:

1. Deploy to a private Vercel project (`vercel.json` is included, with security headers and a CSP).
2. In the Vercel project, enable Deployment Protection (password or SSO). This is a platform setting and needs a plan that includes it. Confirm it is active by opening the URL in a private window before sharing it.
3. Do not share the repository publicly while it contains the media.

## Known limitations

- **No official logo.** The repository has no True.in logo file. The header uses a type wordmark with a lime mark. Replace it in `src/components/Masthead.tsx` (`Wordmark`) when the logo is supplied.
- **No submission endpoint.** The enquiry forms validate input and offer a copyable summary. They never report a successful send. Connect an authorised endpoint before any real enquiries are taken.
- **Video audio.** Source reels contain audio. Every reel is muted and never autoplays with sound. The audio track is still in the preview files because `avconvert` cannot strip it. Re-encode with ffmpeg (without audio) before publication.
- **One source video excluded.** `a001` (1080x1920) cannot be transcoded by `avconvert` on any preset. It needs ffmpeg. See `scripts/build-media.mjs`.
- **Previews only.** Reels are 15-second previews, not full-length films.
- **No launch imagery.** No asset shows a product launch. The launch capability is illustrated with an event announcement poster and described as such.
- **Font licence.** General Sans is self-hosted from the Fontshare archive. The licence text was not extracted into this repository. Confirm the terms before publication.
- **Route bundling.** Routes are bundled eagerly, not split. Lazy routes caused a 0.92 CLS on first load (measured in Lighthouse). This is documented in `src/App.tsx`.
- **Contact details.** No verified business email or phone exists. The WhatsApp link is the community invitation from the Instagram profile, not a business number.

## Required business confirmations

1. The official True.in logo (vector file).
2. A business email, phone, or form endpoint for enquiries.
3. Publication rights for each media item, or a decision to use only owned or commissioned material.
4. Whether the production domain will be used. Canonical URLs and the sitemap need it.
5. Whether the Instagram highlight names (Mercedes, PVR, Crossword, Cherie and others) are confirmed clients. Until they are, they are not shown as clients.
6. Whether the creator and guest photographs may be used with their names or credits, and whether visible people consent to appearing in a proposal.
